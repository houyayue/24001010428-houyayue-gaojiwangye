一、条件结构 if / else if / else

输入一个 0~100 的分数，程序自上而下逐个判断条件，命中即执行对应分支。

if (score >= 90)      { grade = '优秀'; }
else if (score >= 80) { grade = '良好'; }
else if (score >= 60) { grade = '及格'; }
else                  { grade = '不及格'; }
点击"判定等级"查看结果

二、条件结构 switch / case

输入 1~7 的数字，switch 把表达式与各 case 值精确匹配，break 防止贯穿。

switch (day) {
  case 1: name = '星期一'; break;
  case 2: name = '星期二'; break;
  /* … 中间略 … */
  case 7: name = '星期日'; break;
  default: name = '输入无效';
}
点击"switch 判断"查看结果

三、循环结构 for（累加求和）

for 由"初始化；条件；更新"三部分组成，循环变量 i 从 1 走到 n，把每次的 i 累加进 sum。

let sum = 0;
for (let i = 1; i <= n; i++) {
  sum += i;
}
点击"for 求和"查看结果

四、循环结构 while（条件循环）

while 先判断条件再执行循环体，条件不满足即退出——这里用来列出不超过 1000 的 2 的幂。

let p = 1;
while (p <= 1000) {
  list.push(p);
  p *= 2;   // 若忘记更新 p 会造成死循环
}
点击"while 演示"查看结果

五、双重 for 循环 + 条件判断（九九乘法表）

外层循环 i 控制行、内层循环 j 控制列（j ≤ i），再配合条件判断过滤右上三角，形成阶梯状乘法表。

for (let i = 1; i <= 9; i++) {
  for (let j = 1; j <= i; j++) {
    addCell(j + '×' + i + '=' + (i * j));
  }
}
