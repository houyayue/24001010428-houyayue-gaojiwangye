17-2 使用 fetch 跨域获取远程接口数据 —— dog.ceo 随机猎犬图片接口

接口信息

GET https://dog.ceo/api/breed/hound/images/random/3

该接口返回 JSON：{ "message": ["图片地址1", "图片地址2", "图片地址3"], "status": "success" }。服务端已开放 CORS（跨域资源共享），所以浏览器允许我们用 fetch 直接请求，无需后端代理。

接口返回的原始数据（JSON）

fetch 拿到的是响应对象，必须先 response.json() 才能变成 JS 对象，这一步也是异步的。

核心代码（fetch + async/await）

// ① async 函数里用 await 等待异步结果，代码像同步一样好读
async function getDogs() {
  try {
    // ② fetch 发起请求，返回 Promise
    const res = await fetch('https://dog.ceo/api/breed/hound/images/random/3');

    // ③ fetch 只在网络故障时 reject，404 / 500 也算"成功"，要手动判断
    if (!res.ok) throw new Error('HTTP 状态码：' + res.status);

    // ④ response.json() 把响应体解析成 JS 对象（同样是异步）
    const data = await res.json();

    // ⑤ 拿到 data.message 里的图片地址数组，动态创建 img 显示
    data.message.forEach(function (url) {
      const img = document.createElement('img');
      img.src = url;
      document.body.appendChild(img);
    });
  } catch (err) {
    // ⑥ 断网、接口挂了都在这里兜住，页面不会崩
    console.error('请求失败：', err);
  }
}

fetch 使用要点

要点 说明
返回 Promise必须 await 或 .then() 才能拿到结果
res.ok 才代表成功404/500 时 fetch 不报错，要自己判断状态码
res.json() 也是异步它返回 Promise，别忘加 await
跨域靠服务端 CORSdog.ceo 响应头带 Access-Control-Allow-Origin，前端可直接请求
一定要 try...catch断网、超时、解析失败都在这里兜底，页面不会白屏
loading 与错误态请求中显示骨架屏，失败给提示和重试入口，体验才完整
