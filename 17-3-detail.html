详情页的 ID 来自地址栏参数 ?id=（例如 17-3-detail.html?id=3），页面用 URLSearchParams 取出后拼进接口地址，再 fetch 单个商品。没有传 id 时默认取 1 号商品。

核心代码：怎么拿到 URL 里的 ID

// ① 从地址栏 ?id=3 里取出参数
const params = new URLSearchParams(location.search);
const id = params.get('id') || '1';           // 没传就默认 1

// ② 把 ID 拼进接口地址（模板字符串更清爽）
const url = `https://dummyjson.com/products/${id}`;

// ③ fetch + await，注意 404（商品不存在）也要自己判断
const res = await fetch(url);
if (!res.ok) throw new Error('HTTP ' + res.status);

// ④ 拿到单个商品对象，直接取值渲染
const p = await res.json();
document.title = p.title;
