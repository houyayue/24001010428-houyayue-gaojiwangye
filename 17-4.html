核心代码：fetch 发 GET / POST

// —— GET：地址里带参数即可 ——
const res = await fetch('https://jsonplaceholder.typicode.com/posts/1');
const data = await res.json();

// —— POST：第二个参数配置 method / 请求头 / 请求体 ——
const res2 = await fetch('https://jsonplaceholder.typicode.com/posts', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },   // 告诉服务器我发的是 JSON
  body: JSON.stringify({ title: 'foo', body: 'bar', userId: 1 })  // 对象必须转成字符串
});
const created = await res2.json();

// —— 超时中断：AbortController ——
const ctrl = new AbortController();
setTimeout(() => ctrl.abort(), 8000);
fetch(url, { signal: ctrl.signal });   // 超时后请求被取消，进入 catch

常见状态码与错误提示

状态码 / 情况含义本页提示
200 OK请求成功绿色徽章 + 数据
201 Created创建成功（POST 常见）绿色徽章 + 新建对象
404 Not Found资源不存在橙色徽章 + “资源不存在”
500 / 502服务器出错红色徽章 + “服务器错误”
TypeError: Failed to fetch断网 / 域名不存在 / 被 CORS 拒绝红色提示框 + 排查建议
AbortError超过 8 秒被主动中断“请求超时，已中断”
