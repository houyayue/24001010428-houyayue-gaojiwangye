17-5 两种定时器 · setTimeout（延时一次）与 setInterval（每隔一段重复）

两种定时器对照实验 左边只响一次，右边一直响

打个比方：setTimeout 像「定时炸弹」——到点炸一次就结束；setInterval 像「心跳」——每隔一段时间跳一次，不叫停就一直跳。两者都会返回一个 编号 id，要停必须靠它。

① setTimeout —— 延时执行一次

语法：let id = setTimeout(函数, 毫秒)；取消：clearTimeout(id)

实战：定时器能做什么 倒计时 / 打字机

10 秒倒计时用 setInterval 每秒减 1，到 0 时 clearInterval 自己停；打字机用 setTimeout 递归逐字输出，一个字一个字"打"出来。

核心代码

// ① setTimeout：3000 毫秒后执行一次，只执行一次
let timer1 = setTimeout(function () {
  console.log('3 秒到了，我只执行一次');
}, 3000);
clearTimeout(timer1);   // 时间没到就取消，函数不会执行

// ② setInterval：每 1000 毫秒执行一次，不叫停就一直执行
let n = 0;
let timer2 = setInterval(function () {
  n++;
  console.log('第 ' + n + ' 次');
  if (n === 10) clearInterval(timer2);   // 常用套路：满足条件时自己停
}, 1000);

// ③ setTimeout 递归：模拟打字机（比 setInterval 更可控）
function typeOne(i) {
  if (i >= text.length) return;          // 结束条件
  box.textContent += text[i];
  setTimeout(function () { typeOne(i + 1); }, 120);  // 自己调用自己
}

两者区别与注意事项

对比项setTimeoutsetInterval
执行次数延时后只执行 1 次每隔一段时间反复执行
停止方法clearTimeout(id)clearInterval(id)
典型用途延迟提示、防抖、动画开始倒计时、轮播、心跳轮询
嵌套替代用 setTimeout 递归代替 setInterval，可避免"上一轮没跑完就开下一轮"的堆积问题
注意 ①时间单位是毫秒，1000 毫秒 = 1 秒
注意 ②必须先保存返回的 id，否则无法取消（页面关闭前不清理会一直占资源）
注意 ③延时是"最早时间"不是"准点"，JS 单线程忙时会延后
注意 ④回调函数里的 this 默认指向 window，用箭头函数可继承外层 this
