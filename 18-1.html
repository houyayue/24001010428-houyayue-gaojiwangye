动画画布

全部由 Canvas 2D 逐帧绘制：背景星空闪烁、粒子间自动连线成星座、随机划过的流星、两圈环绕光点，以及中央渐变发光 + 缓慢浮动的文字「侯雅月」。用 requestAnimationFrame 驱动，帧率约 60fps。

核心代码

// ① 拿到画笔：getContext('2d') 返回 2D 绘图上下文
const cv = document.getElementById('cv');
const ctx = cv.getContext('2d');

// ② 动画循环：requestAnimationFrame 在下一帧自动回调，比 setInterval 更流畅省电
function loop() {
  ctx.clearRect(0, 0, W, H);          // 清屏（否则上一帧会残留叠影）
  drawStars();                        // 星空：fillStyle + arc + globalAlpha 闪烁
  drawLinks();                        // 星座：距离小于 90px 的粒子之间画细线
  drawMeteors();                      // 流星：moveTo/lineTo + 渐变拖尾
  drawText();                         // 文字：渐变填充 + shadowBlur 发光 + sin 浮动
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);

// ③ 发光文字的关键三行
ctx.font = 'bold 100px "Microsoft YaHei"';
ctx.shadowColor = 'hsl(' + hue + ', 90%, 60%)';   // 光晕颜色随时间流转
ctx.shadowBlur = 30;
ctx.fillStyle = grad;                              // createLinearGradient 双色渐变
ctx.fillText('侯雅月', x, y + Math.sin(t) * 8);    // sin 让文字上下浮动

Canvas 动画要点

技术点本页用法
getContext('2d')获取 2D 绘图上下文，所有绘制都通过它
requestAnimationFrame动画循环，浏览器按刷新率回调（约 60fps），页面隐藏时自动暂停
clearRect每帧先清屏再重画，避免叠影
arc + fill画星星与环绕光点（圆）
createLinearGradient文字渐变色、流星拖尾渐变
shadowBlur文字霓虹发光效果
Math.sin/cos文字上下浮动、光点环绕、星星闪烁（相位差）
随机数星空重铺、流星随机出现位置与角度
