系统架构图（Canvas 绘制）

整张架构图全部用 Canvas 2D 逐帧绘制：5 层架构（用户层 → 接入层 → Web 服务层 → 应用服务层 → 数据层），蓝色光点表示请求下行、绿色光点表示数据返回。把鼠标移到任意节点上可查看该组件的说明。

使用提示：把鼠标移到任意节点上，这里会显示该组件在汽车之家系统中的作用。

核心代码

// ① 画节点：圆角矩形 + 标题 + 副标题
function box(x, y, w, h, title, sub, color, bg) {
  ctx.fillStyle = bg;                       // 底色（浅色调）
  roundRect(x, y, w, h, 8); ctx.fill();
  ctx.strokeStyle = color; ctx.lineWidth = 1.5; roundRect(x, y, w, h, 8); ctx.stroke();
  ctx.fillStyle = '#222'; ctx.font = 'bold 14px "Microsoft YaHei"';
  ctx.fillText(title, x + w/2, y + 22);     // 组件名
  ctx.fillStyle = '#8a94a0'; ctx.font = '11px Consolas';
  ctx.fillText(sub, x + w/2, y + 42);       // 技术栈说明
}

// ② 画箭头：主干线 + 三角形箭头
function arrow(x1, y1, x2, y2) {
  ctx.beginPath(); ctx.moveTo(x1, y1); ctx.lineTo(x2, y2); ctx.stroke();
  const ang = Math.atan2(y2 - y1, x2 - x1);       // 箭头方向角
  ctx.beginPath();                                // 三角形箭头
  ctx.moveTo(x2, y2);
  ctx.lineTo(x2 - 9*Math.cos(ang-0.4), y2 - 9*Math.sin(ang-0.4));
  ctx.lineTo(x2 - 9*Math.cos(ang+0.4), y2 - 9*Math.sin(ang+0.4));
  ctx.fill();
}

// ③ 数据流动画：光点在箭头线段上按 t ∈ [0,1] 插值移动
packet = { seg: arrowIndex, t: 0, spd: 0.006, up: false };
packet.t += packet.spd;
const p = seg.a + (seg.b - seg.a) * packet.t;   // 线性插值算出当前坐标
ctx.arc(p.x, p.y, 4, 0, Math.PI*2); ctx.fill(); // 蓝色=请求下行，绿色=返回上行

// ④ 交互：mousemove 命中检测，悬停高亮 + 显示说明

架构分层说明

层组件作用
用户层PC 浏览器 / 移动 App用户入口，浏览车型库、报价、经销商、社区
接入层CDN + 负载均衡 Nginx静态资源就近加速；请求按权重分发、故障自动摘除
Web 服务层Web 应用集群 + API 网关页面渲染与业务逻辑；统一鉴权、限流、路由
应用服务层车型库 / 报价 / 经销商 / 社区 / 用户中心按业务拆分的微服务，可独立扩容
数据层Redis / MySQL 主从 / Elasticsearch / OSS缓存热点数据、持久化存储、全文搜索、图片文件
