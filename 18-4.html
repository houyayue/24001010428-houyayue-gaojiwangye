ECharts 使用五步法与配置项说明

① 引入 echarts.min.js → ② echarts.init(dom) 初始化实例 → ③ 编写 option 配置 → ④ setOption(option) 渲染 → ⑤ 需要时 setOption 更新（本页树图切换就是重复调用 setOption）。

配置项作用本页用法
title / legend标题、图例折线图标题居中，图例在左上
xAxis / yAxis坐标轴类目轴日期 + 双 value 轴，降雨量轴 inverse: true 倒置
series数据系列type:'line' 面积折线；type:'treemap'/'sunburst' 层级图
tooltip提示框trigger:'axis' + 十字准星 axisPointer
toolbox工具箱dataZoom 区域缩放、restore 还原、saveAsImage 存图
dataZoom数据缩放滑块型 + type:'inside' 滚轮缩放，实时联动
markArea区域标注半透明高亮汛期时间段
universalTransition通用过渡相同 id 的 treemap ↔ sunburst 切换动画

CDN 文件已下载到本地 cdn/ 目录：echarts.min.js（约 1 MB，v5.5.1）与 echarts-package-size.json，页面引用 cdn/echarts.min.js，离线也能运行。
