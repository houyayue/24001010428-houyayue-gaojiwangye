18-6 Mermaid 图表：智能客服系统流程图（flowchart）与 ER 图（erDiagram）

图一：智能客服系统业务流程图

用 Mermaid 的 flowchart TD 语法绘制：用户提问 → 意图识别 → 知识库检索 → 命中判断分支（命中走机器人应答，未命中转人工工单）→ 用户评价 → 知识库更新闭环。菱形为判断节点、虚线为回流线，样式用 classDef 定义。

flowchart TD
    A([用户发起咨询]) --> B[输入预处理
分词 / 敏感词过滤]
    B --> C[意图识别
NLP 分类模型]
    C --> D{意图是否明确？}
    D -- 否 --> E[反问澄清
引导用户补充]
    E --> C
    D -- 是 --> F[知识库检索
向量匹配 Top-N]
    F --> G{置信度 >= 阈值？}
    G -- 是 --> H[组装答案模板
生成机器人回复]
    G -- 否 --> I[创建人工工单
排队转接客服]
    I --> J[人工坐席处理
录入解决方案]
    H --> K([回复用户])
    J --> K
    K --> L[收集用户评价
满意 / 不满意]
    L --> M{评价是否满意？}
    M -- 不满意 --> I
    M -- 满意 --> N[知识条目归档
更新知识库]
    N --> O([会话结束])

    classDef decision fill:#fef9c3,stroke:#ca8a04,color:#713f12
    classDef manual fill:#fce7f3,stroke:#be185d,color:#831843
    class A,K,O startEnd
    class B,C,F,H,E,L,N process
    class D,G,M decision
    class I,J manual

图二：智能客服系统数据库 ER 图

用 Mermaid 的 erDiagram 语法绘制核心实体及关系：用户 ||--o{ 会话 一对多、会话 ||--o{ 消息、消息 ||--o| 反馈评价、知识分类 ||--o{ 知识条目、消息 }o--|| 知识条目（命中引用）、会话 ||--o{ 工单（转人工）。每个实体列出主键与主要属性。

erDiagram
    USER ||--o{ SESSION : "发起"
    USER ||--o{ TICKET : "提交"
    SESSION ||--o{ MESSAGE : "包含"
    SESSION ||--o{ TICKET : "升级为"
    MESSAGE ||--o| FEEDBACK : "获得"
    MESSAGE }o--|| KB_ENTRY : "命中引用"
    KB_CATEGORY ||--o{ KB_ENTRY : "归属"

    USER {
        bigint user_id PK "用户ID"
        varchar nickname "昵称"
        varchar phone "手机号"
        datetime register_time "注册时间"
    }
    SESSION {
        bigint session_id PK "会话ID"
        bigint user_id FK "所属用户"
        varchar channel "渠道(App/网页)"
        datetime start_time "开始时间"
        varchar status "进行中/已结束"
    }
    MESSAGE {
        bigint message_id PK "消息ID"
        bigint session_id FK "所属会话"
        tinyint sender_type "0用户/1机器人/2人工"
        text content "消息内容"
        bigint kb_entry_id FK "命中的知识条目"
        datetime send_time "发送时间"
    }
    KB_CATEGORY {
        int category_id PK "分类ID"
        varchar category_name "分类名称"
        int parent_id FK "父分类"
    }
    KB_ENTRY {
        bigint entry_id PK "知识条目ID"
        int category_id FK "所属分类"
        varchar question "标准问题"
        text answer "标准答案"
        varchar vector_id "向量库索引"
        int hit_count "命中次数"
    }
    TICKET {
        bigint ticket_id PK "工单ID"
        bigint session_id FK "来源会话"
        bigint user_id FK "所属用户"
        varchar issue_type "问题类型"
        varchar handler "处理坐席"
        varchar status "待处理/已完成"
    }
    FEEDBACK {
        bigint feedback_id PK "评价ID"
        bigint message_id FK "被评消息"
        tinyint score "1~5分"
        varchar comment "评价内容"
    }

Mermaid 使用要点

引入本地 cdn/mermaid.min.js → mermaid.initialize({ startOnLoad: true }) → 页面里写 <pre class="mermaid"> 或 <div class="mermaid"> 放入文本语法，加载后自动渲染成 SVG。

语法要素说明本页用法
flowchart TD流程图，TD 为从上到下（LR 为从左到右）智能客服问答主流程
[] / () / ([]) / {}矩形=过程、圆角=起止、 Stadium=端点、菱形=判断意图判断、置信度判断用 {}
--> / --文字--> / -.->实线箭头 / 带标签箭头 / 虚线箭头分支标签「是 / 否」
classDef + class自定义节点配色起止深青、判断黄、人工粉、过程蓝
<br/>节点内换行节点名 + 补充说明两行显示
erDiagram实体关系图7 个实体、7 条关系
||--o{基数符号：||恰好一、o|零或一、}o零或多用户1—多会话、消息0—1评价
PK / FK实体属性标注主键、外键各表主外键与字段类型

mermaid.min.js（v10.9.1，约 3.3 MB）已下载到本地 cdn/ 目录，离线可运行。
